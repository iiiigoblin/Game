# 产物收敛权限（dsh-permission-converge）

为 DeepSeek Harness 的权限菜单增加第四个选项：**产物收敛**。

DeepSeek Harness 的每个权限选项都由两个旋钮组成——**沙盒范围**（能写到哪里）和**审批策略**（是否保留"征求确认"的通道）。「产物收敛」的组合是：沙盒放开到全盘可读写，审批策略保持开启。

## 与既有三个模式的对比

| 模式 | 写入范围 | 审批通道 | 典型使用场景 |
|---|---|---|---|
| 仅可查看 | 只读 | 开启 | 只做检查、阅读、分析 |
| 工作区内修改 | 工作区 + 允许的临时目录 | 开启 | 在项目目录里改代码 |
| 完全权限 | 全盘可写 | 关闭（审批请求会被自动拒绝） | 完全放手，不再被打断 |
| **产物收敛** | **全盘可写** | **开启** | **工作区内外读写，同时保留必要的确认环节** |

### 共同点

- 与「仅可查看」「工作区内修改」一致：审批通道开启，需要确认的操作仍能正常询问。
- 与「完全权限」一致：写入范围覆盖工作区之外。
- 和三个既有选项一样，它由沙盒范围与审批策略共同决定权限行为。

### 区别

- 与「完全权限」的唯一区别是审批策略：`never` → `ask`。`never` 状态下任何审批请求都会被自动拒绝，`ask` 则保留询问能力。
- 与「工作区内修改」的唯一区别是写入范围：不再把工作区外的普通写入拦成审批。

## 安装

在 DeepSeek Harness 的 **插件** 页面选择 **添加插件**，指向本目录（或已打包的压缩包 / 包名），安装后重载生效。安装完成后，权限菜单会多出「产物收敛」一项。

安装只影响权限预设表，不改变当前会话已选的权限；切换后对之后的操作生效。

## 生效范围与限制

- 写入范围与「完全权限」相同：绕过文件沙盒的限制，但仍以当前操作系统用户的身份运行，不是管理员提权。
- 审批通道开启，但普通文件读写不会主动请求审批；只有确实需要确认的步骤才会询问。
- 若同时启用了 DSH 的自动复核（Auto review）预设，两者使用同一对旋钮（全盘可写 + 询问），权限菜单可能把当前选择显示为其中一项，而不是「产物收敛」。
